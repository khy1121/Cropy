## 1. 왜 만드는가

고추 탄저병(*Colletotrichum acutatum*)은 어린 풋고추에 감염된 뒤 증상 없이 잠복하다가
과실이 붉게 익을 때 발현한다. 병반이 보이는 시점은 이미 감염된 지 한참 뒤이고,
살균제는 그 과실을 살리지 못한다.

CropCare AI는 "병반이 찍힌 사진"을 입력으로 받는다. 즉 탄저병에 한해서는 **앱이
작동하는 시점이 방제 타이밍이 지난 시점**이다. 스마트폰 RGB 카메라로는 잠복감염을
원리적으로 볼 수 없으므로 모델을 키워서 풀리지 않는다.

**우회 전략:** 카메라가 보지 못하는 것을 보게 만들 수는 없다. 대신 **배양으로
발현시켜 보이게 만든 다음** 카메라로 센다. 발현된 병반은 뚜렷하므로 현재 모델
(test 93.1%)이 판독기로 충분하다.

다습 배양 검정 자체는 식물병리학의 표준 잠복감염 검정법이다. 이 장치는 그 절차를
농가가 실패 없이 수행하게 하고, 판독과 해석을 자동화한다.

## 2. 제품 정의

**하는 것**
- 무증상 풋고추 24개 표본의 **잠복감염률(%)** 산출
- 하루 3회 촬영으로 **발현 곡선**(며칠째 몇 %) 기록
- 감염률에 따른 **방제 강도 권고**
- 기존 진단 이력과 같은 밭 단위로 **시계열 누적**

**하지 않는 것**
- 분자 검출(PCR/LAMP) — 병원균 동정이 아니라 발현 관찰
- 무증상 과실의 영상 검출 — 배양 전 판정은 하지 않음
- 밭 전체 전수 조사 — 표본 검사이며 통계적 추정
- 치료 — 결과는 "아직 안 걸린 과실을 지킬지" 결정하는 근거

**사용자:** 1차는 고추 재배 농가. 다만 1호당 구매보다 **농업기술센터·작목반 공용
장비**가 현실적인 시작점. 검정 대행 서비스 모델도 같은 장치로 가능.

**사용 시기:** 착과 후 ~ 착색 시작 전. 붉어지기 시작하면 결과가 나와도 조치할 시간이
없다. 같은 밭에서 2~3주 간격 반복하면 감염 압력 추세가 보인다.

## 3. 사용 흐름

농가가 하는 일은 1~4번뿐이다.

| # | 단계 | 시점 | 내용 |
|---|------|------|------|
| 1 | 표본 채취 | D+0 | 밭 여러 지점에서 무증상 풋고추 24개 무작위. 한 곳에서 몰아 따지 않음. 길이 8~12cm |
| 2 | 표면소독 | D+0 | 흐르는 물 세척 → 락스 10배 희석액 1분 → 깨끗한 물 헹굼. 표면 포자를 죽여 **이미 껍질을 뚫고 들어간 감염만** 남긴다. 생략하면 오염도를 재게 됨 |
| 3 | 트레이 배치 | D+0 | 격자 한 칸에 하나씩, 서로 닿지 않게 |
| 4 | 챔버 투입·검사 시작 | D+0 | 물받이에 물, 뚜껑 닫기. 앱에서 밭 선택 → "검사 시작" → 첫 촬영 |
| 5 | 자동 배양·촬영 | D+1~7 | 25~28℃ 고습 유지, 하루 3회 촬영·업로드. 앱에서 칸별 상태 실시간 |
| 6 | 결과 | D+5~7 | 발현 곡선이 평탄해지면 종료. 감염률·권고 표시, 이력 저장 |
| 7 | 세척 | D+7 | 트레이·챔버를 락스 희석액으로. 챔버가 전염원이 되지 않도록 |

## 4. 하드웨어

구성 요소 전부가 검증된 기성품이다. 과학 문제가 아니라 엔지니어링 문제다.

```
┌──────────────────────────────────────┐
│  카메라 격실(건조) · LED+확산판       │  ← 투명창으로 분리, 실리카겔
├──────────────────────────────────────┤
│                                      │
│              (온습도 센서)           │
│                                      │
│  [    ][    ][    ][    ]  격자 트레이  │
│  [    ][    ][    ][    ]  4×6 = 24칸  │
│  [    ][    ][    ][    ]  (6줄 중 3줄) │
│  ~~~~~~ 물받이(고습) ~~~~~~          │
│  ====== 히팅매트 ======              │
└──────────────────────────────────────┘
```

### 설계 결정

- **격자 트레이 4×6 = 24칸, 칸 130×50mm** (트레이 약 550×340mm). 칸 위치가 고정되므로
  객체 검출 없이 **칸을 크롭해 기존 단일이미지 분류기에 그대로 넣는다.** 이 결정
  하나로 모델 재학습이 사라진다.
- **표본 24개.** 30개가 교과서 기준이지만 24가 트레이·화각·챔버 크기에서 균형.
  통계적 한계는 분명하다 — 감염률 20% 부근에서 95% 신뢰구간 약 ±16%p. 등급(낮음/주의/높음)을
  가르기엔 충분하고, 경계 근처는 재검사로 보완한다.
- **Camera Module 3 Wide**, 트레이 위 약 30cm. 12MP에서 칸 하나 약 810×310px —
  224px 입력으로 줄여도 정보가 남음. 2mm 이하 초기 병반은 한계.
- **카메라 격실 분리.** 95% 이상 습도에서 렌즈 결로는 반드시 생긴다. 카메라·LED를
  상부 건조 격실에 두고 투명창 너머로 촬영. 창은 LED 발열로 공기보다 약간 따뜻하게.
- **조명은 촬영 순간만.** 배양은 암조건으로 충분. 5000K·CRI 90+ LED + 확산판 —
  균일 조명이 분류 정확도에 가장 크게 작용.
- **트레이 소재 PETG.** PLA는 습기를 먹는다. 락스 세척을 견뎌야 한다.
- **추론은 장치에서 하지 않는다.** Wi-Fi로 기존 FastAPI 백엔드에 업로드. 장치는
  촬영·전송·온습도 제어만 하는 얇은 기기.

## 5. 소프트웨어

```
장치 펌웨어 (Python on Pi)      →  백엔드 확장 (FastAPI, 기존)   →  앱 (Next.js, 기존)
08·14·20시 촬영                     검사 세션·촬영·칸 결과 테이블      검사 시작 위저드
SHT31 60초 기록, 히터 제어          격자 보정·칸 크롭·칸별 추론        칸 격자 실시간 화면
POST /capture, 실패 시 로컬 큐      시계열 판정                       감염률·곡선·권고
```

### 분석 파이프라인

1. **격자 보정** — 트레이 네 모서리 ArUco 마커를 OpenCV로 검출해 원근 보정. 카메라가
   조금 틀어져도 칸 좌표 고정. 학습 없는 결정적 단계.
2. **칸 크롭** — 24칸을 잘라낸다. 약간의 여백 포함.
3. **칸별 추론** — 기존 `predict_all()`로 9-class 분포를 얻되 **고추 클래스
   {0 탄저, 1 흰가루, 6 정상}만 남기고 재정규화.**
4. **시계열 판정** — **연속 2회 촬영에서 탄저 확률 ≥ 0.6**이면 "발현" 확정. 단발
   오분류 제거. 한 번 발현한 칸은 되돌리지 않음.
5. **감염률·곡선** — 발현 칸 ÷ 24. 촬영마다 기록. 곡선이 48시간 평탄하면 종료 제안.
6. **권고** — 판정 기준표로 방제 강도 매핑.

### 판정 기준 (초기값 — 가설, Phase 3에서 보정)

| 감염률 | 등급 | 권고 |
|--------|------|------|
| 0~5% | 낮음 | 정기 예방 살포 유지. 2~3주 뒤 재검사 |
| 5~20% | 주의 | 강우 전 예방 살포 필수. 아래쪽 과실·이병과 제거 강화. 1~2주 뒤 재검사 |
| 20% 이상 | 높음 | 즉시 살포, 7일 간격. 계통 다른 약제로 교차. 붉은 과실 조기 수확 검토 |

### 모델

**v0는 현재 9-class ResNet50을 손대지 않고 쓴다.** 챔버 안은 조명·배경·거리가
통제되므로 노지보다 조건이 좋다. 다만 학습 데이터(노지)와 배경이 다르므로 도메인
갭은 실측.

검증 중 챔버 이미지가 쌓이면 **챔버 전용 2-class(탄저 발현/정상)** 모델을 따로 학습.
이때 2차 세균성 부패(물러짐) 클래스 추가 여부 결정.

## 6. 검증 계획

각 단계는 통과 기준을 못 넘으면 다음으로 가지 않는다. **Phase 0은 하드웨어를 만들기
전에 한다.**

> **시기가 급하다.** 고추 착색기는 7~9월. **이번 주 안에 풋고추 표본을 따면 이번
> 시즌 안에 Phase 0 데이터가 나온다.** 놓치면 내년 6월 착과기까지 대기. Phase 0은
> 김치통과 스마트폰으로 충분하다.

| Phase | 기간 | 내용 | 통과 기준 |
|-------|------|------|-----------|
| 0 | 2주 · 지금 | 수동 검정 + 기존 모델 판독. 풋고추 24개 → 소독 → 종이 격자 → 밀폐용기 → 매일 스마트폰 촬영. 칸별 크롭을 기존 모델에 넣고 육안 판정과 비교 | 칸별 탄저/정상 정확도 ≥ 90%, 발현 칸 놓침 ≤ 5%. 탄저 외 부패 오판율 기록 |
| 1 | 4주 | 챔버 1호기 + 펌웨어 | 7일 무인 운전에서 25~28℃ 유지율 ≥ 95%, 결로로 판독 불가 0건, 업로드 유실 0건 |
| 2 | 6주 | 백엔드·앱 파이프라인 (ArUco 보정, 칸별 추론, 시계열 판정, 결과 화면) | 격자 검출 실패율 < 1%, 촬영→결과 < 30초, 사용자 3명이 안내만 보고 검사 완료 |
| 3 | 한 시즌 | 현장 검증 (농업기술센터 협력). 농가 10곳+에서 착색 전 검사 → 착색기 실제 발병률 추적. 일부 표본 PCR 교차 검증 | **잠복감염률과 착색기 발병률의 상관이 유의해야 한다.** 없으면 제품 가치 없음. 판정 기준표는 이 데이터로 확정 |

## 8. 특허 관점

다습 배양 검정, 배양 챔버, 카메라 타임랩스, 콜로니 계수기는 모두 공지. 개별 요소로는
신규성 없음. 무게중심은 **조합과 연결**:

- 격자 트레이로 과실 개체를 분리해 **개체별 병반 분류 → 잠복감염률** 산출
- 촬영 시계열에서 **발현 곡선**을 만들고 평탄화로 종료 시점 결정
- 감염률을 **방제 강도 권고로 매핑**, 같은 밭의 기존 영상 진단 이력과 결합

혼동쌍 유도촬영 출원과는 별건. **출원 전 시연·SNS·논문·공모전 공개 금지.**
선행조사 키워드: latent infection incubation imaging, fruit incubation chamber camera
counting, 잠복감염 검정 자동화, 배양 검정 영상 판독.
