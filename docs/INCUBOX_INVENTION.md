# 인큐박스 - 발명신고서 초안 및 출원 준비

**비공개.** 출원 전까지 이 문서와 장치·앱 화면·결과를 외부에 보이지 않는다(시연, SNS,
논문, 공모전, 수업 발표 포함). 공지되면 신규성이 사라진다. 불가피하게 공개해야 하면
공개일로부터 12개월 이내 출원 + 신규성 상실 예외 주장(특허법 §30)이 가능하지만,
해외 출원에 불리하므로 쓰지 않는 것을 원칙으로 한다.

진행 중인 **혼동쌍 유도촬영 출원과는 별건**이다. 기술 분야(배양 검정 장치)와 해결 과제가
다르므로 별도 출원한다. 다만 두 발명이 같은 밭의 이력을 공유하는 부분(종속항)은 상호
참조 가능하다.

## 1. 발명의 명칭

**과실 잠복감염 발현 검정 장치 및 이를 이용한 방제 의사결정 지원 방법**

영문: *Apparatus for incubation-based detection of latent fruit infection and method
for supporting disease control decisions using the same*

## 2. 기술 분야

식물 병해 진단. 구체적으로는 무증상 과실에 잠복한 병원균 감염을 배양으로 발현시키고,
영상으로 개체별 발현 여부를 자동 판독하여 잠복감염률을 산출하고 방제 강도를 결정하는
장치·방법.

## 3. 배경 기술

### 3.1 문제

고추 탄저병 등 잠복감염형 과실 병해는 감염 후 증상 없이 잠복하다가 성숙기에 발현한다.
증상이 보이는 시점은 방제 적기를 지난 시점이며, 살균제는 이미 감염된 과실을 치료하지
못한다. 따라서 방제 판단은 **증상이 보이기 전**에 내려야 하는데, 농가는 잠복감염 여부를
알 수 없어 일률적 정기 살포(과다 살포) 또는 증상 발견 후 살포(실기)에 의존한다.

### 3.2 종래 기술

| 구분 | 내용 | 한계 |
|------|------|------|
| (a) 다습 배양 검정 | 무증상 과실을 표면소독 후 고온다습에 배양해 잠복감염을 발현시키고 육안 계수. 식물병리학 표준법 | 실험실 절차. 농가가 수행하면 소독·온습도·판독 일관성이 없다. 판독은 육안·수기 |
| (b) 분자 검출 (PCR, LAMP) | 병원균 DNA 증폭 | 시약·장비·숙련 필요. 파괴검사. 현장 부적합 |
| (c) 영상 기반 병해 진단 앱 | 스마트폰 사진의 병반을 CNN으로 분류 | **병반이 보여야** 작동. 잠복감염은 원리적으로 검출 불가 |
| (d) 식물 생육·배양 챔버 + 카메라 | 종자 발아·조직배양 등의 타임랩스 관찰 | 관찰·기록 목적. 개체별 감염 판정·감염률·방제 연계 없음 |
| (e) 콜로니 계수기 | 페트리접시 미생물 콜로니 자동 계수 | 균일 배지 위의 점 계수. 과실 개체별 병반 분류가 아님 |
| (f) 분광·초분광 무증상 검출 | NIR 등으로 조직 변화 검출 | 전용 센서, 조도 통제, 연구 단계 |

(a)~(f) 각각은 공지다. 본 발명은 (a)의 배양 검정을 (c)의 분류 모델로 자동 판독하되,
**격자 구획으로 개체를 분리해 개체별 판정을 가능하게 하고**, **촬영 시계열로 발현
확정과 종료 시점을 결정하며**, **감염률을 방제 강도와 기존 영상 진단 이력에 연결**하는
조합에 특징이 있다.

## 4. 해결하려는 과제

1. 증상 발현 전 단계에서 밭의 잠복감염 수준을 **농가가 수행 가능한 절차로** 정량화한다.
2. 배양 중 개체별 발현 여부를 **객체 검출 없이** 기존 단일 이미지 분류기로 판정한다.
3. 단발 오분류와 2차 부패를 **시계열 규칙**으로 걸러 발현을 확정한다.
4. 발현 곡선의 평탄화로 **검정 종료 시점을 자동 결정**한다.
5. 잠복감염률을 **방제 강도 권고**로 변환하고, 같은 포장의 영상 진단 이력과 결합한다.

## 5. 과제의 해결 수단 (발명의 구성)

### 구성 A — 격자 구획 트레이

복수의 구획(셀)을 갖는 트레이. 각 셀은 과실 1개를 수용하고 인접 과실과 접촉을 차단한다.
트레이 모서리에 **기준 마커**(ArUco 등)를 구비해 촬영 영상에서 트레이 평면을 정규 좌표계로
변환할 수 있게 한다. 셀 위치는 정규 좌표계에서 상수이므로 **객체 검출 없이** 셀 영역을
잘라낼 수 있다.

### 구성 B — 배양 챔버

트레이를 수용하고 온도(25~28℃)·습도(RH 85% 이상)를 유지하는 단열 챔버. 히터와 수반,
온습도 센서. 촬영부는 배양 공간과 **투명창으로 분리된 건조 격실**에 두어 결로를 방지한다.
조명은 촬영 시에만 점등한다.

### 구성 C — 시계열 촬영·전송부

정해진 주기(예: 1일 3회)로 트레이 전체를 촬영해 환경값과 함께 서버로 전송한다. 전송
실패 시 순서를 보존하는 큐에 보관한다.

### 구성 D — 셀별 판독부

서버에서 (1) 기준 마커로 원근 보정, (2) 셀 영역 크롭, (3) **병해 분류 모델**로 셀별 발현
확률 산출. 분류 모델은 작물의 병해·정상 클래스를 출력하는 기존 모델을 그대로 쓰되,
해당 작물 클래스만 남기고 **재정규화**한다.

### 구성 E — 시계열 판정부

셀 상태를 {정상, 의심, 발현, 무효}로 두고 래치한다. **연속 N회(예: 2회) 촬영에서 발현
확률이 임계 이상**이면 발현으로 확정하며, 한 번 발현한 셀은 되돌리지 않는다. 첫 촬영에서
이미 발현한 셀은 채취 오류로 무효 처리한다.

### 구성 F — 감염률·발현 곡선·종료 결정부

발현 셀 수 / 유효 셀 수 = 잠복감염률. 촬영마다 기록해 발현 곡선을 만들고, **일정 기간
새 발현이 없으면(평탄) 종료를 제안**한다. 최대 기간 초과 시 자동 종료.

### 구성 G — 방제 의사결정 지원부

잠복감염률을 등급(예: 낮음/주의/높음)으로 변환하고 등급별 방제 행동과 등록 약제를
제시한다. 표본 수에 따른 신뢰구간을 함께 제시하고 경계 근처면 재검사를 권고한다. 같은
포장 식별자를 갖는 **영상 진단 이력**(증상 기반)과 결합해 시계열로 제시한다.

### 구성 H — 절차 강제 인터페이스

사용자 단말에서 검정 시작 전 **표면소독 단계를 건너뛸 수 없게** 타이머와 확인을 요구하고,
채취 구역 지정으로 표본 편향을 줄인다. 소독 확인이 없으면 검정 세션을 생성하지 않는다.

## 6. 청구항 초안

> 변리사 검토 전 초안. 독립항은 넓게, 종속항으로 좁혀간다. 구성 H·G는 소프트웨어 특성이
> 강하므로 장치항에 묶기보다 방법항·종속항으로 둔다.

**[청구항 1] (장치)**
과실 잠복감염 발현 검정 장치로서,
복수의 셀로 구획되어 각 셀에 과실 1개를 수용하며 가장자리에 복수의 기준 마커를 구비한
트레이;
상기 트레이를 수용하고 기 설정된 온도 및 습도를 유지하는 배양 챔버;
상기 배양 챔버의 배양 공간과 투명창으로 분리된 격실에 배치되어 상기 트레이를 기 설정된
주기로 촬영하는 촬영부; 및
상기 촬영부의 영상을 외부 서버로 전송하는 통신부를 포함하고,
상기 서버는 상기 기준 마커를 이용해 영상을 정규 좌표계로 변환하고, 상기 정규 좌표계에서
상수로 정의된 각 셀 영역을 잘라내어 병해 분류 모델에 입력함으로써 셀별 발현 확률을
산출하는 것을 특징으로 하는 장치.

**[청구항 2]** 제1항에 있어서, 상기 서버는 연속된 복수 회의 촬영에서 셀의 발현 확률이
임계값 이상일 때 해당 셀을 발현으로 확정하고, 확정된 셀의 상태를 이후 촬영에서 유지하는
장치.

**[청구항 3]** 제2항에 있어서, 상기 서버는 발현으로 확정된 셀 수를 유효 셀 수로 나눈
잠복감염률을 촬영마다 산출하여 발현 곡선을 생성하고, 기 설정된 기간 동안 새로운 발현이
없으면 검정 종료를 결정하는 장치.

**[청구항 4]** 제1항에 있어서, 상기 병해 분류 모델은 복수 작물의 병해 및 정상 클래스를
출력하도록 학습된 모델이고, 상기 서버는 검정 대상 작물에 해당하는 클래스의 출력만을
재정규화하여 발현 확률을 산출하는 장치.

**[청구항 5]** 제1항에 있어서, 상기 서버는 첫 촬영에서 발현 확률이 임계값 이상인 셀을
무효로 처리하여 잠복감염률 산출에서 제외하는 장치.

**[청구항 6]** 제1항에 있어서, 상기 촬영부는 상기 격실 내에 배치된 제어부의 발열로 상기
투명창의 온도를 배양 공간보다 높게 유지하여 결로를 방지하는 장치.

**[청구항 7]** 제1항에 있어서, 상기 통신부는 전송 실패한 영상을 촬영 순서를 보존하는
큐에 보관하고 통신 복구 시 순서대로 전송하는 장치.

**[청구항 8] (방법)**
서버가 수행하는 과실 잠복감염 기반 방제 의사결정 지원 방법으로서,
(a) 사용자 단말로부터 포장 식별자와 표면소독 완료 확인을 수신하여 검정 세션을 생성하는
단계 — 상기 확인이 없으면 세션을 생성하지 않음;
(b) 배양 챔버로부터 기 설정된 주기로 촬영된 트레이 영상을 수신하는 단계;
(c) 영상의 기준 마커로 정규 좌표계 변환 후 셀 영역별로 병해 분류 모델을 적용하여 셀별
발현 확률을 산출하는 단계;
(d) 연속 복수 회 촬영의 발현 확률로 셀별 발현을 확정하고 잠복감염률을 산출하는 단계;
(e) 잠복감염률을 기 설정된 등급으로 변환하고 등급별 방제 행동을 상기 사용자 단말에
제시하는 단계를 포함하는 방법.

**[청구항 9]** 제8항에 있어서, 상기 (e) 단계는 상기 포장 식별자와 동일한 식별자를 갖는,
증상 영상 기반 병해 진단 이력을 조회하여 상기 잠복감염률과 함께 시계열로 제시하는 방법.

**[청구항 10]** 제8항에 있어서, 상기 (e) 단계는 유효 셀 수에 기초한 잠복감염률의
신뢰구간을 산출하고, 등급 경계가 신뢰구간에 포함되면 재검정을 권고하는 방법.

**[청구항 11]** 제8항에 있어서, 상기 (a) 단계는 사용자 단말에 기 설정된 소독 시간의
타이머를 제공하고 타이머 종료 전에는 소독 완료 확인 입력을 비활성화하는 방법.

**[청구항 12] (매체)** 제8항 내지 제11항 중 어느 한 항의 방법을 컴퓨터에 실행시키기 위한
프로그램을 기록한 컴퓨터 판독 가능 기록매체.

## 7. 실시예

[INCUBOX_HARDWARE](INCUBOX_HARDWARE.md), [INCUBOX_PIPELINE](INCUBOX_PIPELINE.md)의 내용이
실시예다. 명세서에는 다음을 구체 수치로 쓴다.

- 트레이: 4×6 = 24셀, 셀 130×50mm, ArUco DICT_4X4_50 ID 0~3.
- 챔버: 25~28℃ 히스테리시스(25.5 ON / 27.5 OFF), RH ≥ 85%, 촬영 1일 3회.
- 판독: ResNet50 9-class(고추·무·배추 병해 6 + 정상 3), 고추 클래스 {탄저, 흰가루, 정상}
  재정규화, 임계 0.60, 연속 2회 확정, 평탄 6회(48시간), 최대 10일.
- 등급: < 5% 낮음 / 5~20% 주의 / ≥ 20% 높음 (실시예 값. 청구항에는 넣지 않음).
- 실측 데이터: Phase 0 결과(칸별 정확도, FN)와 Phase 1 운전 로그를 **reduction to
  practice** 근거로 첨부. Phase 0가 끝나는 대로 출원하는 것이 이상적이다 — 현장 검증
  (Phase 3)까지 기다리지 않는다.
