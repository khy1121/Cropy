## 1. 모바일 웹앱

### M-01 홈 / 진단

```
┌──────────────────────────────┐
│ 🌱 CropCare AI        [가A]   │  ← AppBar, 오른쪽 글자크기 토글
├──────────────────────────────┤
│ 어떤 작물인가요?               │
│ ┌────┐ ┌────┐ ┌────┐          │  ← 작물 칩, 가로 스와이프
│ │🌶고추│ │🥬배추│ │🥕 무 │          │     선택 시 brand 옐로우 채움
│ └────┘ └────┘ └────┘          │
│                              │
│ ┌──────────────────────────┐ │
│ │      📷                  │ │
│ │   잎을 찍어주세요          │ │  ← 큰 촬영 영역(카드), 탭 시 카메라
│ │  또는 사진 선택            │ │     capture="environment"
│ └──────────────────────────┘ │
│                              │
│ 💡 촬영 팁                    │
│ · 잎 한 장이 화면에 꽉 차게    │
│ · 그늘에서, 흔들리지 않게      │
├──────────────────────────────┤
│   [📷 진단]      [🕒 이력]    │  ← BottomNav (md 이상에선 AppBar로 이동)
└──────────────────────────────┘
```

- **사용자 행동**: 작물 칩 선택 → 촬영 카드 탭
- **시스템 반응**: 후면 카메라 즉시 호출. 작물 미선택 시 칩 흔들림 + "작물을 먼저 골라주세요"
- **디자인 노트**: 첫 화면에 설명 문단 없음. 행동 두 개(작물, 촬영)만 보이게

### M-05 재촬영 유도 패널 (S2) ★

```
┌──────────────────────────────┐
│ ◀  진단 결과                  │
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ ⚠ 두 병이 비슷하게 나왔어요│ │  ← signal-med(amber) 톤 패널, 결과 위에 배치
│ │                          │ │
│ │ 무 검은무늬병  51%  ████▌ │ │
│ │ 무 노균병      43%  ███▊  │ │
│ │                          │ │
│ │ 🔍 잎 뒷면을 가까이       │ │
│ │    찍어주세요              │ │  ← 판별 부위 (굵게)
│ │                          │ │
│ │ 뒷면에 회백색 곰팡이층이   │ │
│ │ 보이면 → 노균병           │ │  ← 클래스별 단서(cue)
│ │ 없고 앞면 반점만 뚜렷 →   │ │
│ │ 검은무늬병                │ │
│ │                          │ │
│ │ [📷 뒷면 찍어서 재확정]    │ │  ← brand 옐로우
│ │  이대로 볼래요             │ │  ← 텍스트 링크(건너뛰기)
│ └──────────────────────────┘ │
│                              │
│ (아래는 1차 결과: 검은무늬병) │  ← 흐리게(임시 결과임을 표시)
└──────────────────────────────┘
```

- **사용자 행동**: 잎 뒤집어 촬영 → 재확정
- **시스템 반응**: 1차·2차 분포 융합 → M-06
- **디자인 노트**: "왜 다시 찍는지"와 "무엇을 봐야 하는지"를 반드시 문장으로. 확률 막대는 접전임을 직관적으로 보이게

## 2. 독립 단말 (오렌지파이 5)

화면이 없으므로 스토리보드는 **LED 상태 · 음성 대사 · 사용자 동작** 세 줄로 표현한다.

| 상태 | LED | 의미 |
|---|---|---|
| 대기 | 초록 상시 | 버튼·음성 대기 |
| 듣는 중 | 파랑 | 마이크 활성 |
| 촬영 | 흰색 1회 점멸 | 셔터 |
| 진단 중 | 노랑 | 추론 (약 2초) |
| 결과 | 초록 2회 점멸 | 낭독 시작 |
| 오류 | 빨강 점멸 | 재시도·폴백 |

### D-01 대기

```
[LED] 초록
[단말] (무음)
[사용자] 버튼 누름  또는  "이거 뭐야" / "진단해줘"
```

### D-02 촬영·진단 (S3)

```
[LED] 파랑 → 흰 점멸 → 노랑
[단말] "잎을 카메라 앞에 대주세요. 셋, 둘, 하나… 찰칵."
       "살펴볼게요."
[사용자] 잎을 카메라 10~20cm 앞에 댐
```
- 프레임 안에 초록 영역이 충분히 잡히면 자동 셔터, 아니면 "조금 더 가까이요" 1회 안내

### D-03 결과 낭독 (S3)

```
[LED] 초록 2회 점멸 → 초록
[단말] "무 검은무늬병으로 보여요. 확률은 88%예요."
       "뿌릴 수 있는 약은 ○○○ 수화제예요. 물 1,000배로 희석하세요.
        수확 14일 전까지만 쓸 수 있고, 3번까지 뿌릴 수 있어요."
       "다시 들으시려면 '다시', 예방법은 '예방'이라고 말해주세요."
[사용자] "다시" → 농약 문장 반복 / "예방" → 예방법 낭독 / 무응답 10초 → 대기
```
- **원칙**: 농약명·희석배수·PHI는 백엔드 JSON 값을 그대로 읽음. 음성 모델이 문장 다듬기는 하되 숫자·이름은 바꾸지 못함

### D-04 재촬영 유도 (S4) ★

```
[LED] 노랑 → 파랑
[단말] "검은무늬병인지 노균병인지 헷갈려요.
        잎을 뒤집어서 뒷면을 카메라에 대주세요.
        뒷면에 하얀 곰팡이가 있는지 볼게요."
[사용자] 잎 뒤집어 댐
[LED] 흰 점멸 → 노랑 → 초록
[단말] "뒷면을 보니 노균병이에요. 확률은 70%예요." → (D-03 농약 안내로 이어짐)
```
- 재촬영 거부("그냥 알려줘") 시 1차 결과로 낭독하되 "확실하지 않아요"를 앞에 붙임

### D-05 오류·폴백

```
[음성 인식 실패 2회]
[LED] 빨강 점멸
[단말] "잘 못 들었어요. 버튼을 눌러주세요."

[카메라 오류]
[단말] "카메라가 안 보여요. 선을 확인해주세요."

[배터리 부족]
[단말] "배터리가 얼마 없어요. 충전해주세요."
```

## 3. PC 프로토타입 대응표 (보드 도착 전)

| 단말 요소 | PC 프로토타입 대체 |
|---|---|
| GPIO 버튼 | 키보드 스페이스바 |
| LED | 터미널 색상 문자열 / 작은 Tk 창 |
| 카메라 | 노트북 웹캠 (OpenCV) |
| 마이크·스피커 | 노트북 내장 |
| SUDA 음성 | 임시 오프라인 STT/TTS (SUDA 회신 후 교체) |

에이전트 로직은 보드와 동일하게 유지하고, 위 항목만 어댑터로 분리한다.

## 4. 발표용 데모 순서 (제안)

4. D-01 → D-03: PC 프로토타입 음성 진단 (60초)
5. (보드 도착 시) 실물 단말 시연
