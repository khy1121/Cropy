## 1. 원칙

1. **한 화면에 행동 1~2개.** 첫 화면은 "작물 고르기 + 찍기"만.
2. **글자 크기**: 폰 본문 16px 이상, 고령 모드(가A 토글) 18px 이상, 키오스크 24px 이상. 문서용 14px는 앱 화면에 쓰지 않는다.
3. **터치 타깃**: 최소 48px, 인접 타깃 간격 8px. 키오스크는 72px.
4. **대비**: 텍스트 4.5:1 이상. 주요 색에 파랑 계열을 쓰지 않는다(고령 시인성). 심각도는 색 + 텍스트 + 아이콘으로 중복 표현.
5. **아이콘**: Lucide 세트, 항상 라벨과 함께. 이모지를 아이콘으로 쓰지 않는다(작물 칩의 🌶🥬🥕만 예외).
6. **상태 화면 필수**: 로딩(스켈레톤 + 한 문장), 빈 화면(다음 행동 버튼), 오류(원인 + 복구 버튼).
7. **사실은 DB 값 그대로**: 농약명·희석배수·PHI·횟수는 PSIS 데이터에서 온 값만 표시·낭독한다.
8. **되돌리기 제공**: "이대로 볼래요", "그냥 알려줘", "취소"처럼 막다른 화면을 만들지 않는다.

## 4. 레퍼런스 조사와 채택 내용

- **ui-ux-pro-max** (nextlevelbuilder): 79 스타일·192 팔레트·119 UX 규칙 데이터셋. Agriculture/Farm Tech 팔레트는 Earth Green + Harvest Gold. 우리는 골드를 주색으로 쓰고 초록은 신호색에만 남겼다(기존 브랜드 결정 유지). 체크리스트(이모지 아이콘 금지, 4.5:1, 스켈레톤 로딩, 빈 화면 안내, 오류 복구 경로, 터치 44/48 + 8px 간격, 본문 16px)를 원칙에 반영.
- **고령층 친화 디지털 접근성 10대 지침 · 시니어 UX Tips**: 큰 글자·명확한 대비, 필수 요소만, 얕은 계층, 쉬운 용어, 상태 가시화, 큰 버튼과 간격, 즉각 피드백, 오류 예방·되돌리기, 파랑 계열 주요색 회피, 아이콘+라벨.
- **WWIT(wwit.design)**: 국내 앱 패턴 라이브러리. 홈 = 앱바 + 주 CTA + 칩 + 카드 + 하단 탭, 로딩 = 스켈레톤 + 한 문장 카피. M-01·M-03 구조로 채택.
- **당근 SEED 디자인 시스템**: bg/fg/stroke 토큰 계층, 얇은 구분선과 넉넉한 여백. 토큰 네이밍 차용.
- **Plantix**: 카메라 스캐너가 항상 한 탭 거리, 결과는 병명 → 처방 순.
- **Vercel Web Interface Guidelines**: 로딩 문구 말줄임표(…), 아이콘 버튼 aria-label, prefers-reduced-motion, 인라인 오류 + 첫 오류로 포커스.
- **skills.sh / antigravity-awesome-skills**: 설치 가능한 관련 스킬 — `ui-ux-pro-max`, `frontend-design`(이미 사용 중), `web-design-guidelines`, `minimalist-ui`, `anti-ui-slop`, `deterministic-design`. 설치 명령은 5장 참고.
- **AndroidUICollection**: 네이티브 안드로이드 라이브러리 모음이라 웹앱에는 직접 적용 불가. 카메라 크롭·시머 로딩 아이디어만 참고.

## 6. 앱 화면 v2 (Hi-fi) — 피그마 `📱 3b. 앱 화면 v2`

와이어프레임(M-01~10)이 "카드에 정보를 나열한" 형태라 생성물 티가 났다. v2는 실제 카메라 앱과 국내 서비스(당근·토스)의 결과 화면 문법을 따른다.

- **잎이 주인공**: 홈은 큰 한 문장 + 작물 타일 + 하단 중앙 셔터. 뷰파인더는 어두운 화면에 노란 잎 가이드선. 결과는 상단 사진 위로 시트가 올라온다.
- **한 곳에만 대담함**: 재촬영 유도 화면의 잎 일러스트에 판별 부위(뒷면)를 노란 점선으로 표시. 두 후보는 갈색/초록 분할 막대로 비교.
- **카드 남용 제거**: 섹션은 여백과 헤어라인으로 구분. 숫자(희석배수)는 크게, 설명은 문장으로.
- **카피**: "잎을 찍으면 병과 약을 알려드려요", "둘 중 하나예요. 잎 뒷면을 보면 알 수 있어요", 심각도는 "빨리 방제해야 해요"처럼 행동 문장으로.
- **기기 크롬**: 상태바, 홈 인디케이터, 시트 핸들, 읽어주기 버튼.
- 일러스트 컴포넌트 `Illustration/Leaf/front`, `Illustration/Leaf/back-highlight`(SVG, 스케일 제약). 사진 톤 토큰 `photo/deep·leaf·leaf-light·spot`, `overlay/scrim`.

프론트엔드 반영 우선순위: ① 홈 셔터 바 ② 결과 시트 구조 ③ 재촬영 유도 일러스트 ④ 이력 월별 목록.
