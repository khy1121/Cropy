# 인큐박스 - 검정 절차서 (SOP)

고추 탄저병 잠복감염 다습 배양 검정의 표준 절차. 장치 유무와 관계없이 이 절차가
결과의 신뢰도를 결정한다. **특히 2단계(표면소독)를 생략하면 결과가 무효다.**

두 가지 모드를 다룬다.

| 모드 | 장비 | 용도 |
|------|------|------|
| **수동 모드** | 밀폐용기 + 스마트폰 | Phase 0 검증, 장치 없는 농가 |
| **장치 모드** | 인큐박스 + 앱 | Phase 1 이후 |

절차는 동일하고 촬영·판독 주체만 다르다.

## 원리

탄저병균(*Colletotrichum acutatum*)은 풋고추 표피를 뚫고 들어간 뒤 증상 없이 잠복한다.
과실이 익거나 약해지면 발현한다. **고온다습 조건은 이 발현을 며칠 안으로 앞당긴다.**

표면소독이 핵심인 이유: 소독 없이 배양하면 껍질에 묻어 있던 포자까지 자란다. 그건
"오염도"다. 소독하면 표면 포자는 죽고 **이미 조직 안에 들어간 감염만** 발현한다. 그게
잠복감염률이다.

## 준비물

### 수동 모드

| 품목 | 규격 | 비고 |
|------|------|------|
| 밀폐용기 | 내부 바닥 ≥ 340×550mm, 또는 작은 용기 2개에 12개씩 | 대형 김치통, 스티로폼 박스 |
| 격자 종이 | 가로 4칸 × 세로 6줄, 칸 130×50mm, 칸 번호 인쇄 | A3 2장 이어붙임. 비닐 코팅 권장 |
| 키친타월 또는 신문지 | 바닥 2~3겹 | 젖은 상태 유지 |
| 락스 | 시판 4~5% 차아염소산나트륨 | 10배 희석 → 약 0.4~0.5% |
| 용기 2개 | 소독용 · 헹굼용 | |
| 일회용 장갑 | | 락스 접촉 방지 |
| 스마트폰 + 고정 거치 | 삼각대, 또는 상자 위에 고정 | **매번 같은 위치·높이** |
| 기록지 | [부록 A](#부록-a-기록지) 출력 | |

### 장치 모드

인큐박스 본체, 격자 트레이, 물받이, 락스, 장갑. 앱이 나머지를 안내한다.

## 절차

### 1. 표본 채취 (D+0, 오전 권장)

- **대상:** 육안상 병반이 없는 풋고추. 길이 8~12cm. 상처·벌레 먹은 자리 없는 것.
- **수:** 24개.
- **지점:** 밭을 6구역으로 나누고 **구역당 4개**. 한 포기에서 2개 이상 따지 않는다.
  아래쪽 1~2단(지면 가까운 과실)을 구역당 최소 1개 포함한다 — 빗물 튐으로 먼저
  감염되는 자리다.
- **기록:** 구역별 채취 위치를 기록지에 적는다. 앱은 구역 지정을 안내한다.
- **운반:** 비닐봉지에 담지 않는다(결로). 종이봉투 또는 뚜껑 없는 용기. **채취 후
  4시간 이내** 소독 단계로.

> 채취 편향이 가장 흔한 오류다. "눈에 띄는 것" "큰 것" "따기 쉬운 것"을 고르면 결과가
> 밭을 대표하지 않는다. 구역을 정하고 위치에서 가장 가까운 과실을 딴다.

### 2. 표면소독 (D+0)

장갑을 낀다.

1. 흐르는 수돗물에 흙·이물을 씻어낸다.
2. **락스 10배 희석액**(락스 1 : 물 9)에 **1분** 담근다. 전체가 잠기도록. 타이머를
   쓴다 — 30초 이하면 불충분, 3분 이상이면 표피가 손상된다.
3. 깨끗한 물에 **30초 이상** 헹군다. 2회.
4. 키친타월 위에 놓고 물기를 뺀다. 문지르지 않는다.

> 락스 희석액은 당일 만든 것만 쓴다. 햇빛·시간에 분해된다.
> 장치 모드에서는 앱이 이 단계에 1분 타이머를 띄우고, 완료 확인 없이는 다음 단계로
> 넘어가지 않는다.

### 3. 배치 (D+0)

- 격자 칸마다 **하나씩**. 칸 번호 순서(1~24)로.
- 과실끼리 **닿지 않게**. 닿으면 병반이 옮겨가 개체별 판정이 깨진다.
- 꼭지는 같은 방향(예: 모두 위쪽)으로. 판독 일관성.
- 수동 모드: 격자 종이 위에 배치 후 젖은 키친타월은 **격자 종이 아래**가 아니라
  **용기 가장자리**에 둔다. 과실이 물에 직접 닿으면 2차 부패(세균성 물러짐)가 생겨
  탄저 병반과 혼동된다.
- 장치 모드: 트레이에 배치 → 물받이에 물 500mL → 트레이를 물받이 위 거치대에.

### 4. 배양 (D+0 ~ D+7)

| 조건 | 목표 | 허용 | 이탈 시 |
|------|------|------|---------|
| 온도 | 25~28℃ | 23~30℃ | 20℃ 이하 지속 → 발현 지연, 기간 연장. 32℃ 이상 → 세균 부패 증가 |
| 습도 | 95% 이상 | 85% 이상 | 85% 미만 → 물 보충. 발현 억제됨 |
| 광 | 암 또는 실내 산란광 | | 직사광선 금지(온도 폭주) |

- 수동 모드: 뚜껑을 닫고 실내 그늘. 여름철 실내(26~29℃)면 별도 가온 불필요.
  봄·가을은 보일러 방 또는 전기장판 약 위에.
- 하루 1회 뚜껑을 열어 **환기 10초**, 키친타월 마름 확인. 열었을 때 촬영.
- 장치 모드: 장치가 유지·기록한다. 앱이 이탈 시 알림.

### 5. 판독·촬영 (매일)

**수동 모드:**
- **매일 같은 시각**(예: 아침), 같은 위치·높이·조명에서 촬영. 창가 역광 금지.
- 격자 전체가 한 장에 들어오게. 격자 네 모서리가 보이게.
- 촬영 후 육안 판정을 기록지에 적는다. 판정 기준은 아래.
- 파일명: `YYYYMMDD_HHMM.jpg`. 밭 이름 폴더에 모은다.

**장치 모드:** 08·14·20시 자동 촬영. 앱에서 칸별 상태 확인.

#### 육안 판정 기준

| 판정 | 기준 |
|------|------|
| **정상** | 변화 없음, 또는 단순 시듦·주름 |
| **탄저 발현** | 움푹 팬 원형~타원형 병반. 갈색~흑갈색. 병반 위 **검은 점(분생포자층)** 또는 **분홍~주황색 포자 덩어리**. 동심원 무늬 |
| **2차 부패** | 물러짐, 악취, 투명해짐, 회색 곰팡이(잿빛곰팡이), 흰 솜털 — **탄저가 아님** |
| **불명** | 위 어느 것도 확실치 않음. 다음 날 재판정 |

탄저와 2차 부패의 구분: 탄저는 **경계가 뚜렷하고 움푹** 패며 조직이 비교적 단단하다.
부패는 경계가 번지고 물컹하다. 의심되면 "불명"으로 두고 다음 날 본다 — 탄저면
포자층이 뚜렷해진다.

### 6. 종료 (D+5~7)

- **종료 조건:** 2일 연속 새 발현이 없고, 시작 후 5일 이상 경과.
- **최대 10일.** 그 이후는 2차 부패가 많아져 판독 불가.
- 최종 감염률 = 발현 과실 수 ÷ 판정 가능 과실 수. 2차 부패로 판독 불가한 과실은
  분모에서 뺀다(기록지에 표시).

### 7. 폐기·세척 (종료 당일)

- 과실은 **밭으로 가져가지 않는다.** 밀봉해 종량제 봉투, 또는 매몰.
- 용기·트레이·격자판: 락스 10배 희석액으로 닦고 헹궈 말린다.
- 챔버 내부(장치 모드): 물받이 비우고 락스 희석액으로 닦는다. 카메라 창은 마른 천.

## 결과 해석

| 감염률 | 등급 | 의미 |
|--------|------|------|
| 0~5% | 낮음 | 잠복 압력 낮음. 정기 예방 유지 |
| 5~20% | 주의 | 착색기에 같은 비율이 터진다. 강우 전 살포 필수 |
| 20% 이상 | 높음 | 즉시 살포. 계통 교차. 조기 수확 검토 |

24개 표본의 통계적 한계: 감염률 20% 부근에서 95% 신뢰구간은 **약 ±16%p**다.
등급 경계 근처(예: 4~6%, 18~22%)면 **1~2주 뒤 재검사**로 보완한다. 같은 밭의
반복 결과가 추세를 만든다 — 단일 결과보다 추세가 더 믿을 만하다.

> 이 등급 경계는 초기 가설이다. 현장 검증([INCUBOX_VALIDATION](INCUBOX_VALIDATION.md))으로
> 보정한다.

## 흔한 실패와 원인

| 증상 | 원인 | 대응 |
|------|------|------|
| 거의 모든 과실에 병반 | 소독 생략·불충분 → 표면 포자 | 무효. 재검사 |
| 물러지고 악취 | 과실이 물에 닿음, 온도 과다 | 키친타월 위치 조정, 온도 확인 |
| 7일 지나도 변화 없음 | 온도 낮음(20℃ 이하) | 가온. 기간 연장 |
| 흰 솜털·회색 곰팡이 | 잿빛곰팡이 등 2차 감염 | 탄저 아님. 분모에서 제외 |
| 과실 2개가 같이 썩음 | 서로 닿음 | 배치 시 간격 |
