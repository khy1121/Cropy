# 인큐박스 - 앱 UI 사양

기존 Next.js 앱에 "검사" 기능을 더한다. 디자인 시스템은 기존 그대로(`tailwind.config.js`의
paper/ink/khaki/brand/signal 토큰, Pretendard, 당근 스타일, 모바일 우선, 큰글씨 모드).
새 토큰·새 글꼴·새 장식 없음.

## 내비게이션

BottomNav(모바일) / AppBar 필(md 이상)에 탭 하나 추가.

| 탭 | 아이콘 | 경로 | 비고 |
|----|--------|------|------|
| 진단 | `lucide--camera` | `/` | 기존 |
| **검사** | `lucide--flask-conical` | `/incubation` | **신규** |
| 이력 | `lucide--history` | `/history` | 기존. 검사 결과도 여기 섞여 보인다 (아래) |

## 화면 목록

```
/incubation                 검사 홈: 진행 중 카드 + 시작 버튼 + 최근 결과
/incubation/new             시작 위저드 (5단계)
/incubation/[id]            진행·결과 화면 (status에 따라 같은 페이지가 두 모습)
/incubation/[id]/manual     수동 모드 사진 업로드 + 4점 지정
/incubation/devices         장치 목록·추가 (페어 코드)
/history                    기존 + 검사 결과 카드 혼합
/history/[id]               기존 진단 상세 (변경 없음)
```

컴포넌트(신규): `IncubationHome`, `IncubationWizard`, `CellGrid`, `ExpressionCurve`,
`IncubationResult`, `ClimateStrip`, `CornerPicker`, `DevicePairing`.

## /incubation — 검사 홈

```
┌──────────────────────────────┐
│ 검사                          │  AppBar
├──────────────────────────────┤
│ 진행 중                        │
│ ┌──────────────────────────┐ │
│ │ 윗밭 · 3일째               │ │  카드: field_label · day
│ │ 12.5%  발현 3 / 24        │ │  큰 숫자(font-extrabold, tnum)
│ │ ▮▮▮▮▮▮▮▮▮▯▯▯ 관찰 중 2     │ │  미니 진행 바 + suspect 수
│ │ ⚠ 물을 보충하세요          │ │  활성 경고 (signal-med-tint)
│ └──────────────────────────┘ │
│                              │
│ [ 새 검사 시작 ]              │  brand 버튼, 전폭, 높이 56
│                              │
│ 최근 결과                      │
│  윗밭   8/10   4.2%  낮음  ›  │  리스트, 등급 pill(signal)
│  아랫밭 7/28  25.0%  높음  ›  │
│                              │
│ 장치: 작목반 1호기 · 대기 중   │  작게, khaki. 탭하면 /devices
└──────────────────────────────┘
```

- 진행 중 run이 없으면 카드 자리에 **빈 상태**: 그림 없이 두 줄 —
  "착과 후 ~ 붉어지기 전에 검사하세요" / "풋고추 24개와 락스만 있으면 됩니다".
- 장치가 하나도 없으면 시작 버튼 아래에 "장치 없이 수동으로 검사하기" 보조 링크.

## /incubation/new — 시작 위저드

한 화면에 한 단계. 상단에 단계 표시(1/5). **뒤로 가기 가능, 건너뛰기 불가.**
큰글씨 모드에서도 한 화면에 들어가도록 단계당 텍스트 5줄 이내.

### 1. 밭과 장치

- 밭 이름: 기존 `field_label` 자동완성(최근 사용 순) + 직접 입력.
- 장치 선택: 등록된 장치 목록(대기 중인 것만 선택 가능) / "수동 모드(스마트폰 촬영)".
- 작물: `고추` 고정 표시 (확장 전까지 선택 불가, 회색).

### 2. 표본 채취 안내

```
풋고추 24개를 따세요

밭을 6구역으로 나누고
구역마다 4개씩.
한 포기에서 2개 이상 따지 마세요.
아래쪽 과실을 구역마다 1개 이상 넣으세요.

[ 구역 그림 ]  ← 6칸 격자, 탭하면 채취 완료 체크 (6/6이 되면 다음 활성화)

병반이 보이는 것은 빼세요. 길이 8~12cm.
```

채취 시각(`sampled_at`)은 이 단계 완료 시각으로 기록.

### 3. 표면소독 — 건너뛸 수 없음

```
락스 10배 희석액에 1분 담그세요

락스 1 : 물 9
전체가 잠기도록

[ ▶ 1:00 타이머 시작 ]   ← 누르면 카운트다운. 0이 되면 다음 문구

깨끗한 물에 30초씩 2번 헹구세요

[ ✓ 소독과 헹굼을 마쳤습니다 ]   ← 타이머 종료 전에는 비활성
```

- 타이머를 돌리지 않고는 확인 버튼이 활성화되지 않는다. 앱을 닫았다 열어도 타이머 상태 유지(로컬 스토리지).
- 확인 시각이 `disinfection_confirmed_at`.
- 이 단계가 왜 중요한지 한 줄: "소독하지 않으면 껍질에 묻은 포자까지 자라 결과가 틀립니다."

### 4. 배치

```
한 칸에 하나씩 놓으세요

서로 닿지 않게.
꼭지는 모두 같은 쪽으로.

[ 트레이 그림: 4×6, 번호 ]

물받이에 물 500mL를 붓고 뚜껑을 닫으세요   ← 장치 모드
젖은 키친타월을 용기 가장자리에 두세요        ← 수동 모드
```

### 5. 시작

- 요약 카드: 밭 · 장치 · 채취 시각 · 소독 확인 시각.
- `[ 검사 시작 ]` → `POST /incubation` → 장치 모드면 "장치가 첫 사진을 찍는 중…"
  (assignment 폴링 대기, 최대 2분) → `/incubation/[id]`.
- 수동 모드면 바로 `/incubation/[id]/manual`로 가서 D+0 사진 촬영.

```
┌──────────────────────────────┐
│ ‹ 윗밭                        │
├──────────────────────────────┤
│ 3일째 · 마지막 촬영 14:00      │  muted
│                              │
│ 12.5%                        │  text-5xl font-extrabold tnum
│ 발현 3 · 관찰 중 2 · 정상 19   │  sm, 색 점으로 구분
│                              │
│ ┌ 발현 곡선 ────────────────┐ │
│ │        ╭──                │ │  ExpressionCurve (SVG, 120px 높이)
│ │    ╭───╯                  │ │  x: 일, y: %. 마지막 점 강조
│ │ ───╯                      │ │  평탄 구간은 점선
│ └───────────────────────────┘ │
│                              │
│ ┌ 칸별 상태 ────────────────┐ │
│ │ [1][2][3][4]              │ │  CellGrid 4×6
│ │ [5][●][7][8]              │ │  ● expressed = signal-high
│ │ [9][◐]…                   │ │  ◐ suspect   = signal-med
│ │                           │ │  ○ healthy   = khaki-tint
│ └───────────────────────────┘ │  ✕ invalid   = line 색, 대각선
│ 칸을 누르면 사진을 볼 수 있어요 │
│                              │
│ ┌ 환경 ──────────────────────┐ │
│ │ 26.4℃  96%  히터 31%       │ │  ClimateStrip. 범위 밖이면 signal-med
│ └───────────────────────────┘ │
│                              │
│ ⚠ 물을 보충하세요 (1시간 전)   │  활성 경고 목록
│                              │
│ [ 검사 종료 ]                 │  평탄이면 brand, 아니면 outline
└──────────────────────────────┘
```

- **칸 탭** → 바텀시트: 해당 칸의 최신 크롭(큼) + 이전 촬영 썸네일 가로 스크롤 + 확률
  (`탄저 0.91`). 사진은 `/uploads/incubation/{run}/cells/{seq}/{cell}.jpg`.
- **평탄(plateau=true)** 이면 곡선 아래에 콜아웃(brand-tint): "2일째 변화가 없습니다.
  종료해도 됩니다." 종료 버튼이 brand로 바뀐다.
- `day ≥ 10` 자동 종료되면 결과 화면으로.
- 폴링: 30초 간격 `GET /incubation/{id}`. 화면 떠나면 중단.
- 수동 모드: 환경 카드 대신 "오늘 사진 올리기" 버튼 (→ `/manual`). 마지막 업로드 24시간
  지나면 signal-med로 "오늘 사진을 아직 올리지 않았어요".

등급 밴드는 **DB에서 온 grade**만 표시한다. 프론트에서 감염률로 등급을 다시 계산하지
않는다 (기존 severity 규칙과 동일: 진실은 서버에).

## /incubation/[id]/manual — 수동 업로드

1. 카메라/갤러리에서 사진 선택 (기존 DiagnoseForm의 파일 입력 재사용).
2. **CornerPicker**: 사진 위에 격자 네 모서리를 순서대로 탭. 좌상 → 우상 → 우하 → 좌하.
   탭할 때마다 번호 점이 찍히고 연결선이 그려진다. 마지막 점 후 사각형이 닫히면 "다시 찍기" / "올리기".
   이전 업로드의 네 점을 기본값으로 미리 찍어둔다(거치가 고정이면 그대로 확인만).
3. 올리기 → `POST /manual-capture` → 결과 반영 → 진행 화면.

## /incubation/devices — 장치

- 목록: label · 상태(대기/검사 중/오프라인) · 마지막 접속 · 펌웨어.
- `[ 장치 추가 ]` → `POST /devices/pair-code` → 6자리 코드 큰 글씨 + "장치에서
  `incubox provision --pair-code 482913`" + 남은 시간. 등록되면 자동으로 목록 갱신.
- 장치 이름 변경, 삭제.

## /history 통합

기존 이력 목록에 검사 결과 카드를 시간순으로 섞는다. 구분은 카드 좌측 아이콘
(`lucide--camera` vs `lucide--flask-conical`)과 제목 형식:

| 종류 | 제목 | 부제 |
|------|------|------|
| 진단 | 고추 탄저병 | 87% · 8/20 |
| 검사 | 윗밭 잠복감염 검사 | 12.5% 주의 · 8/22~8/29 |

필터 칩에 "진단 / 검사" 추가. API는 `/history`와 `/incubation`을 각각 부르고 프론트에서
병합(페이지 크기 작으니 충분).

## 상태·색 규칙

| 상태 | 색 | 형태 |
|------|-----|------|
| healthy | `khaki-tint` 배경, `khaki` 테두리 | ○ |
| suspect | `signal-med-tint` 배경, `signal-med` 테두리 | ◐ (반 채움) |
| expressed | `signal-high-tint` 배경, `signal-high` 채움 | ● |
| invalid | `line` 배경, 대각선 1줄 | ✕ |
| 등급 low / caution / high | `signal-low / med / high` 밴드 | 기존 severity 밴드와 동일 |

색에만 의존하지 않는다 — 형태(채움 정도)와 텍스트 라벨이 항상 같이 간다.
큰글씨 모드에서 칸 그리드는 4열 유지, 칸 높이만 커진다.

## 카피 원칙

- 사용자가 하는 일은 동사로, 한 줄에 하나: "따세요" "담그세요" "놓으세요".
- 숫자는 먼저: "24개" "1분" "500mL".
- 결과 화면은 등급 → 한 줄 이유 → 할 일 순서. 확률·신뢰구간은 그 아래 작게.
- 오류: 무엇이 잘못됐고 무엇을 하면 되는지. "장치가 2분째 응답이 없어요. 전원과
  Wi-Fi를 확인해 주세요."
