## 금주 수행결과

### 1. 주요 수행 내용 및 팀원 개인별 수행 업무

**주요 수행 내용**

- 프로젝트 주제를 "농작물(고추·무·배추) 병해충 이미지 AI 진단 및 농약 안내 서비스"로 확정
- 기획서 초안(v0.1), 시나리오 스케치, 스토리보드 3종 문서 팀 공유 및 검토
- 진행 방식 결정: 오렌지파이 보드 지급 전까지는 스마트폰 브라우저 기반 **웹앱**으로 개발하고, 보드 지급 후 단말로 이식
- 역할 분담 확정: PM·모델(김헌영) / 프론트엔드(김민서) / 백엔드(박성호) / 카메라·음성(고명준) / 디바이스·인프라(이서하), 문서·발표는 4명 로테이션
- 코드 충돌 방지를 위해 폴더 단위 소유권과 파트 간 API 계약 규칙 수립 (`.github/CODEOWNERS`)
- 14주 개발 일정 초안 수립 (중간 발표 7주차, 최종 발표 14주차)

### 2. 주요 문제점

- 오렌지파이 보드 지급 시점이 미정이라 단말 관련 작업(하드웨어 조립, NPU 배포) 착수 시기를 확정할 수 없음
- 단말 음성 기능에 사용할 음성 엔진의 보드(RK3588) 지원 여부가 미확인 상태

### 3. 해결 방법

- 보드 지급 전까지 웹앱 중심으로 개발하고, 디바이스 담당은 브라우저 카메라 모듈·부품 발주·변환 툴 환경 준비 등 보드 없이 가능한 작업을 선행
- 음성 엔진은 브라우저 Web Speech API로 먼저 검증하고, 보드 지원 여부 확인 후 대체 엔진(오프라인 STT/TTS) 폴백 방안을 함께 준비

(주1) 팀활동 관련 인증사진, 화상회의 캡쳐화면, 통화기록, 이메일 사진은 별첨으로 첨부
