# 우선순위 백로그

> 작성일: 2026-09-03 · 전제: **오렌지파이 5 미보유** (지급 여부 미정).
> 원칙: **보드 없이 지금 PC에서 되는 일**을 앞에, 보드가 와야만 되는 일은 "대기 트랙"으로 분리.
> 보드 없이도 전체 파이프라인의 90%(양자화·에이전트·SUDA 협의)는 진행 가능하다.

## 우선순위 판단 기준

1. **차단 해제 우선** — 외부 의존(마음AI 회신, 보드 지급)은 리드타임이 기니 **먼저 던져놓는다**
2. **보드 무관 우선** — PC에서 완결되는 작업부터
3. **가설 검증 우선** — "음성만으로 되는가"를 싸게 먼저 확인
