# 인큐박스 - 하드웨어 사양

프로토타입 1호기 기준. 양산 설계(사출 챔버, 통합 PCB)는 1호기 검증 후 별도 문서.

## 설계 목표

| 항목 | 목표 |
|------|------|
| 배양 조건 | 25~28℃, RH 95% 이상, 7일 무인 유지 |
| 촬영 | 24칸 트레이 전체를 한 장에, 칸당 ≥ 250px 단변, 결로 없음 |
| 표본 | 풋고추 24개 (4×6), 길이 8~12cm |
| 전원 | 단일 12V 어댑터 |
| 연결 | Wi-Fi (2.4GHz) |
| 세척 | 내부 전체를 락스 희석액으로 닦을 수 있을 것 |
| 비용 | 20만원 이하 |

## 전체 구조

```
        ┌────────────────────────────────────────────┐
   상부  │  [Pi Zero 2 W]  [카메라]  [LED바][LED바]     │  카메라 격실 (건조, 뚜껑 안쪽)
   격실  │       실리카겔           확산판             │  높이 60mm
        ├═══════════ 아크릴 투명창 (3mm) ═════════════┤
        │                                            │  높이 연장 링 150mm
        │                  ↓ 촬영거리 300mm            │  (스티로폼 판)
   배양  │          (SHT31 센서, 측벽 중간)            │
   공간  │                                            │  박스 본체
        │   ┌──┬──┬──┬──┐                            │  내부 ≥ 580×380×300
        │   │  │  │  │  │  격자 트레이 4×6             │
        │   │  │  │  │  │  약 550×340mm               │
        │   └──┴──┴──┴──┘  (거치대 위 40mm)           │
        │   ~~~~~~~~ 물받이 ~~~~~~~~                   │
        │   ======= 히팅매트 =======                   │
        └────────────────────────────────────────────┘
```

본체는 **대형 스티로폼 보냉박스**(내부 약 580×380×300mm, 두께 30mm — 수산물용 대형
규격). 단열이 좋아 14W 히터로 충분하고, 칼로 가공되며, 싸다. 트레이(550mm)가 들어가려면
내부 장변 **580mm 이상**이어야 한다. 촬영 거리를 확보하려고 본체와 뚜껑 사이에
**높이 연장 링**(스티로폼 판 30mm 두께로 만든 150mm 높이 틀)을 끼우고, 뚜껑 안쪽에
카메라 격실을 만든다.

## 카메라 기하

**Camera Module 3 Wide** (IMX708, 12MP 4608×2592, 수평 화각 약 102°, 오토포커스).

| 항목 | 값 | 계산 |
|------|-----|------|
| 촬영 거리 (렌즈→트레이 상면) | 300mm | 격실 바닥 ~ 트레이 상면 |
| 수평 커버 | 약 740mm | 2 × 300 × tan(51°) |
| 수직 커버 (약 67°) | 약 400mm | 2 × 300 × tan(33.5°) |
| 트레이 | 550 × 340mm | 장변을 수평축에 |
| 해상도 | 약 6.2 px/mm | 4608 / 740 |
| 칸 130×50mm | 약 810 × 310 px | |
| 2mm 병반 | 약 12px | 검출 하한 |

트레이가 수평 화각의 약 74%, 수직 85%를 차지한다. 광각 렌즈의 주변부 왜곡은 ArUco
원근 보정이 흡수하지만, 트레이를 **화면 중앙**에 두고 거리를 300mm 아래로 줄이지
않는다 (수직 여유가 60mm뿐이다).

**포커스는 고정한다.** 오토포커스가 매번 다른 곳을 잡으면 칸별 비교가 흔들린다.
초기 설정 시 트레이 상면에 맞춘 `LensPosition`을 펌웨어 설정에 기록한다
([INCUBOX_FIRMWARE](INCUBOX_FIRMWARE.md)).

표준 Camera Module 3(비광각, 수평 66°)을 쓰면 같은 커버에 거리 ~500mm가 필요해
박스가 너무 높아진다. Wide가 맞다.

## 카메라 격실 (결로 대책)

RH 95% 공간에서 렌즈는 반드시 결로된다. 대책은 **격리 + 온도차 + 흡습**.

- 뚜껑 안쪽에 60mm 높이 격실. 바닥은 **3mm 아크릴판**, 실리콘으로 밀봉.
- **Pi Zero 2 W를 격실 안에** 둔다. 약 1W 발열이 격실 공기를 배양 공간보다 1~2℃
  높게 유지해 창 안쪽 결로를 막는다. 별도 히터 불필요.
- 격실에 **실리카겔 50g** (재생 가능한 지시약형). 7일마다 교체·건조.
- 창 **바깥쪽**(배양 공간 쪽) 결로: 배양 공간 공기가 창보다 따뜻하면 생긴다. 격실이
  더 따뜻하므로 평상시엔 없다. 히터 과열 방지로 충분.
- 창에 **AR(무반사) 필름**은 선택. LED 반사가 화면에 들어오면 LED 위치를 창 가장자리로.

## 조명

- **5000K, CRI ≥ 90 LED 바 2개** (12V, 각 2.5W), 격실 양쪽 가장자리에 트레이 방향으로.
- **확산판**(유백 아크릴 2mm)을 LED 앞에. 직사 LED는 과실 표면 하이라이트를 만들어
  병반을 가린다.
- **촬영 때만 점등**: 촬영 2초 전 ON → 촬영 → OFF. 배양은 암조건으로 충분하고,
  연속 점등은 격실 온도를 올린다.
- 균일도 목표: 트레이 네 모서리와 중앙의 밝기 차 **20% 이내**. 초기 설정 시 흰 종이로 측정.

## 온습도

### 가온

- **12V 파충류 히팅매트 14W** (약 280×280mm). 물받이 아래, 박스 바닥에.
- 매트는 물받이의 물을 데워 습도와 온도를 동시에 올린다.
- 제어: **히스테리시스**. 25.5℃ 미만 ON, 27.5℃ 초과 OFF. 목표 26.5℃.
- 과열 보호: 센서 31℃ 초과 또는 센서 오류 시 **무조건 OFF** + 앱 알림.
- 열 예산: 스티로폼 30mm 박스(약 0.5m² 표면)의 열손실은 실온 20℃에서 약 5~7W.
  14W면 실온 15℃까지 26℃ 유지 가능. 그 이하(겨울)는 대상 아님.
- 여름 실내(28℃ 이상)에서는 히터가 거의 켜지지 않는다. **냉각은 없다** — 30℃ 이상
  실내에 두지 말 것을 앱이 안내한다.

### 가습

- 물받이(약 500mL)만으로 밀폐 공간 RH 95~100% 도달. 능동 가습 없음.
- 센서가 RH 85% 미만을 1시간 이상 보고하면 앱 알림 "물 보충".

### 센서

- **SHT31** (I²C, 주소 0x44). 정확도 ±2%RH, ±0.3℃.
- 위치: 배양 공간 측벽 중간 높이, 트레이 상면 높이. 히터 직상 금지.
- 센서 보호: 고습에서 장기간 쓰면 표류한다. 방수 멤브레인 버전(SHT31-D 모듈) 또는
  PTFE 테이프로 감싼다.

## 격자 트레이

```
  ArUco 0 ┌──────────────────────────────────────────────┐ ArUco 1
          │ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ │
          │ │   1    │ │   2    │ │   3    │ │   4    │ │   칸 내부 130×50
          │ └────────┘ └────────┘ └────────┘ └────────┘ │   (가로 130, 세로 50)
          │ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ │
          │ │   5    │ │   6    │ │   7    │ │   8    │ │   칸막이 4, 높이 25
          │ └────────┘ └────────┘ └────────┘ └────────┘ │
          │      ⋮  (6줄, 줄마다 4칸, 번호는 가로 방향)  │
          │ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐ │
          │ │   21   │ │   22   │ │   23   │ │   24   │ │
          │ └────────┘ └────────┘ └────────┘ └────────┘ │
  ArUco 3 └──────────────────────────────────────────────┘ ArUco 2
                         외곽 550 × 340
```

| 항목 | 값 |
|------|-----|
| 외곽 | 550 × 340 × 25mm (테두리 8mm) |
| 칸 | 가로(장축) 4칸 × 세로(단축) 6줄 = 24. 내부 130 × 50mm, 칸막이 4mm, 높이 25mm |
| 치수 검산 | 장축 8 + 4×130 + 3×4 + 8 = 548 ≈ 550. 단축 8 + 6×50 + 5×4 + 8 = 336 ≈ 340 |
| 칸 배열 | 과실 장축(130)이 트레이 장축과 평행. 카메라에서 트레이 장축이 화면 가로 |
| 번호 | 좌상 1 → 오른쪽으로 4 → 다음 줄. `cell_index = 번호 − 1` |
| 바닥 | **배수 슬릿** 2mm × 5개/칸. 과실이 고인 물에 닿지 않게 |
| 각인 | 칸 번호를 칸 바닥 구석에 양각 (판독 대조용, 과실에 가려지는 위치) |
| 마커 | **ArUco DICT_4X4_50, ID 0·1·2·3**, 30×30mm, 테두리 네 모서리에 좌상부터 시계방향 |
| 소재 | **PETG** (흡습 낮음, 락스 내성, 60℃까지). PLA 불가 |
| 색 | **무광 중회색** (RAL 7042 근처). 흰색은 노출 튀고 검정은 그림자 정보 손실 |
| 출력 | 베드 크기 한계로 **2분할(275×340 × 2)** + 더브테일 결합 |

마커는 출력 후 **흰 바탕 검정 인쇄 스티커**를 음각 자리에 붙인다. 3D 프린트 마커는
대비가 부족하다. 스티커 위에 투명 방수 테이프.

거치대: 트레이를 물받이 위 40mm에 띄우는 ㄷ자 받침 2개 (PETG 또는 스테인리스 봉).

## 전기

### 부품 결선

```
12V 3A 어댑터 ─┬─ 벅컨버터(12→5V 3A) ─ Pi Zero 2 W (5V/GND 핀 직결)
               ├─ MOSFET 모듈 A ─ 히팅매트 14W      ← Pi GPIO18
               └─ MOSFET 모듈 B ─ LED 바 ×2 (5W)    ← Pi GPIO12

Pi GPIO2 (SDA) ─ SHT31 SDA
Pi GPIO3 (SCL) ─ SHT31 SCL
Pi 3.3V / GND  ─ SHT31 VCC / GND
Pi CSI (mini)  ─ Camera Module 3 Wide (Zero용 22→15핀 케이블)
```

| 핀 | 용도 | 비고 |
|----|------|------|
| GPIO2 / GPIO3 | I²C SDA / SCL | SHT31. 풀업은 모듈 내장 |
| GPIO12 | LED MOSFET 게이트 | 촬영 시 HIGH |
| GPIO18 | 히터 MOSFET 게이트 | 히스테리시스 ON/OFF. PWM 불필요 |
| GPIO17 | 상태 LED (선택) | 격실 외부에서 보이는 동작 표시 |
| 5V / GND | 전원 | 벅컨버터 출력. USB 포트 대신 헤더 직결 |

MOSFET 모듈은 로직 레벨 N-ch(예: IRLZ44N 기반 모듈). 3.3V 게이트로 풀 구동되는 것.
히터 라인에 **1A 퓨즈**.

### 전력 예산

| 부하 | 전력 | 동시성 |
|------|------|--------|
| Pi Zero 2 W (Wi-Fi + 카메라 동작) | 최대 3W | 상시 |
| 히팅매트 | 14W | 간헐 (듀티 ≤ 50%) |
| LED 바 ×2 | 5W | 촬영 시 수 초 |
| SHT31 | < 0.01W | |
| **합계 피크** | **약 22W** | 어댑터 36W로 여유 |

전원 단절 시: Pi는 재부팅 후 스케줄을 이어간다 ([INCUBOX_FIRMWARE](INCUBOX_FIRMWARE.md)).
히터는 재부팅 전까지 OFF(MOSFET 게이트 풀다운). RTC가 없으므로 NTP 복구 전까지는
시각 미상 — 펌웨어가 처리.

### 안전

- 12V 저전압 시스템. 상용 전원은 어댑터 안쪽에만.
- 히터는 물받이 **아래 박스 바닥**, 물과 직접 접촉 금지. 매트 위에 물받이를 두되 매트
  전선 인입부는 물받이 밖으로.
- 격실(전자부)과 배양 공간(고습)은 아크릴 창으로 완전 분리. 전선은 실리콘 그로밋으로 관통.
- 과열 차단: 센서 31℃ 또는 센서 무응답 시 히터 OFF (펌웨어) + 히팅매트 자체의
  서모스탯(있는 제품 선택).

## 조립 순서

1. 스티로폼 판으로 높이 연장 링(내부 치수 = 박스 내부, 높이 150mm)을 만들어 본체 위에 얹고 실리콘으로 고정. 뚜껑 안쪽에 격실 틀(PETG 또는 폼보드)을 만들고 아크릴 창을 실리콘으로 밀봉. 24시간 경화.
2. 격실에 Pi·카메라·LED·확산판 장착. 카메라 렌즈가 창 중앙, 트레이를 정면으로.
3. 박스 바닥에 히팅매트, 위에 물받이, 거치대, 트레이.
4. 측벽 중간에 SHT31. 전선은 측벽 관통(그로밋).
5. 벅컨버터·MOSFET 모듈은 격실 또는 박스 **외부** 소형 케이스.
6. 전원 인가 → 펌웨어 프로비저닝 → **초기 설정**: 포커스 고정, 노출 고정, 조명 균일도
   측정, ArUco 4개 검출 확인.
7. 빈 트레이로 7일 건조 운전: 온도 유지율, 결로, 업로드 확인.
