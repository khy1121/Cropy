# CropCare AI - Product Requirements Document

**Version:** 1.1

## 1. 프로젝트 개요

### 프로젝트명
CropCare AI

### 프로젝트 목적
농작물 병해충은 조기 발견이 가장 중요하지만, 대부분의 농업인은 병해충을 정확히 구분하지 못하며 적절한 농약과 방제 방법을 찾기 위해 많은 시간을 소비한다.

본 프로젝트는 CNN 기반 이미지 인식 기술과 공공데이터를 활용하여 병해충을 자동 진단하고, 등록 농약·예방 방법·발병 원인 및 관리법까지 제공하는 AI 기반 스마트 농업 플랫폼을 구축한다.

단순히 병명을 알려주는 서비스가 아닌, **실제 농업 현장에서 활용 가능한 의사결정 지원 서비스**가 목표이다.

### 대상 범위
고추·무·배추 3개 작물, 병해 6종 + 정상 3종 (총 9개 진단 클래스).

## 2. 개발 목표

사용자는 사진 한 장만 촬영하면 아래 정보를 받을 수 있다.

| 기능 | 설명 |
|------|------|
| 병해충 진단 | CNN 모델 기반 이미지 분류 |
| 신뢰도 제공 | Top-1 / Top-3 예측 및 confidence score |
| **혼동쌍 유도촬영** | **구분이 어려운 두 병해가 접전일 때 판별부위 재촬영을 안내하고 결과를 재확정** |
| 병 설명 | 증상, 영향, 심각도 |
| 원인 분석 | 환경·기후·관리 요인 |
| 등록 농약 추천 | 공공데이터(PSIS) 기반 허가 농약 |
| 희석비 안내 | 농약별 사용 농도 |
| 사용 방법 | 살포 시기·방법 |
| 안전사용기준 | PHI(수확 전 일수), 사용 횟수 |
| 예방 방법 | 재발 방지 관리법 |
| 진단 이력 저장 | 과거 진단 조회 |

## 3. 핵심 차별점 — 혼동쌍 유도촬영

일반적인 이미지 진단 서비스는 사진 한 장으로 확률만 제시하고, 애매한 경우에도
가장 높은 후보를 그대로 답한다. 그러나 실측 결과 **오분류의 절반 이상이 특정
두 병해 사이에서 발생**한다.

test 637장 중 오분류 44건, 그중 **26건(59.1%)이 무 검은무늬병 ↔ 무 노균병
상호 오분류**다. 두 병은 잎 앞면 사진만으로는 구분 정보 자체가 부족하다.
**모델을 키워서 풀리는 문제가 아니라 입력에 판별 정보가 없는 문제**다.

본 서비스는 이 지점에서 사용자를 개입시킨다.

1. 상위 두 후보가 사전 정의된 혼동쌍이고 신뢰도 마진이 좁으면(< 0.20)
2. 두 병을 가르는 **특정 부위**(예: 잎 뒷면)와 **무엇을 봐야 하는지**를 함께 안내하고
3. 재촬영한 사진과 1차 사진의 예측 분포를 **가중 융합**해 진단을 재확정한다

농업인이 무엇을 확인해야 하는지 배우게 된다는 점에서, 블랙박스 확률 제시보다
현장 의사결정에 직접적으로 기여한다.

상세 설계와 실측 근거는 [MODEL_SPEC.md](MODEL_SPEC.md#혼동쌍-유도촬영) 참고.

## 4. 사용자 시나리오

1. 농업인이 작물 잎/과실 사진을 촬영 또는 업로드
2. AI가 병해충을 진단하고 신뢰도와 함께 결과 표시
3. **두 병해가 접전이면 "잎 뒷면을 찍어주세요" 안내 → 재촬영 → 진단 재확정**
4. 병 설명, 원인, 방제·예방 정보 확인
5. 추천 농약 및 희석비·안전사용기준 확인
6. 진단 결과가 이력에 자동 저장

## 5. 비기능 요구사항

- 모바일 웹 우선 (현장 촬영). 카메라 직접 호출(`capture="environment"`)
- 진단 API 응답 5초 이내 (목표)
- 한국어 UI 및 콘텐츠
- 공공데이터(농약안전정보, 작물병해충) 연동 가능 구조
- 모델 미배포 상태에서도 전 구간 동작 (Mock 모드)

## 8. 후속 과제

**정확도**
- 무노균병 학습 데이터 확보 (현재 175장, 타 클래스의 절반)
- 판별부위(잎 뒷면 근접) 이미지 수집 — 전용 분류기가 실효를 내려면 선행 필요
- 혼동쌍 정의를 실측 혼동행렬 기반으로 주기적 갱신

**운영**
- 업로드 크기 상한 및 오래된 업로드 정리
- 재확정에 사용한 2차 사진의 이력 기록
- 시드 데이터 갱신 반영 (현재 insert-only라 변경분 미반영)
- 사용자 인증 도입 후 이력 분리
