# 인큐박스 - 검증 계획

각 Phase는 통과 기준을 못 넘으면 다음으로 가지 않는다. 기준은 숫자로 쓰고, 측정 방법을
같이 쓴다. "잘 된다"는 기준이 아니다.

```
Phase 0  수동 검정 + 기존 모델        2주   ← 지금. 하드웨어 없이
Phase 1  챔버 1호기 + 펌웨어          4주
Phase 2  백엔드·앱 파이프라인         6주
Phase 3  현장 검증 (한 시즌)          2027 착과기~착색기
```

## 시즌 제약

고추 착과 6월 ~ 착색 7~9월. **Phase 0은 2026년 8월 말까지 표본을 따야 이번 시즌에
끝난다.** 9월 중순 이후엔 풋고추가 줄고 이미 발병한 과실이 많아 표본이 나쁘다.
놓치면 Phase 0이 2027년 6월로 밀리고, Phase 3은 2028년이 된다.

겨울엔 Phase 1·2(하드웨어·소프트웨어)를 진행한다. 모델 판독 검증은 Phase 0 데이터로 충분.

## 지표 정의

모든 Phase에서 같은 정의를 쓴다.

### 칸 수준 (모델 판독)

육안 판정([INCUBOX_PROTOCOL](INCUBOX_PROTOCOL.md) 기준표)을 정답으로 둔다. 판정자 2명이
독립 판정하고 불일치는 사진을 보며 합의. **"불명"은 제외**, "2차 부패"는 별도 집계.

| 지표 | 정의 | 목표 |
|------|------|------|
| 칸별 정확도 | (탄저↔탄저 + 정상↔정상) / 판정 가능 칸 | ≥ 90% |
| **FN (놓침)** | 육안 탄저인데 모델 `expressed` 아님 / 육안 탄저 | **≤ 5%** |
| FP (오경보) | 육안 정상인데 모델 `expressed` / 육안 정상 | ≤ 10% |
| 부패 오판율 | 육안 2차 부패인데 모델 `expressed` / 육안 2차 부패 | 측정만 (목표 없음, 대응 결정용) |
| 확정 지연 | 육안 첫 발현 촬영 → 모델 `expressed` 확정 촬영 간 회수 | 중앙값 ≤ 1회 (8시간) |
| Cohen's κ (판정자 간) | 두 판정자의 일치도 | ≥ 0.8 (정답 자체의 신뢰성) |

FN이 FP보다 중요하다. 놓치면 감염률이 과소추정되어 "낮음"으로 잘못 안심시킨다.
FP는 재검사로 걸러지지만 FN은 걸러지지 않는다.

### 검사 수준

| 지표 | 정의 | 목표 |
|------|------|------|
| 감염률 오차 | \|모델 감염률 − 육안 감염률\| | ≤ 1칸 (4.2%p) |
| 등급 일치 | 모델 등급 == 육안 등급 | ≥ 90% (경계 ±1칸 제외) |
| 종료 시점 일치 | 모델 평탄 제안일 vs 육안 "2일 변화 없음" | ±1일 |

### 장치 수준 (Phase 1)

| 지표 | 정의 | 목표 |
|------|------|------|
| 온도 유지율 | 60초 로그 중 25~28℃ 비율 (시작 2시간 제외) | ≥ 95% |
| RH 유지율 | RH ≥ 85% 비율 | ≥ 98% |
| 결로 판독 불가 | ArUco 검출 실패 또는 선명도 < 임계인 촬영 수 | 0 |
| 업로드 유실 | 장치 seq 수 − 서버 수신 수 | 0 |
| 무인 운전 | 사람 개입 없이 연속 | 7일 |

### 현장 수준 (Phase 3)

| 지표 | 정의 | 목표 |
|------|------|------|
| **예측 상관** | 착색 전 잠복감염률 vs 착색기 실제 발병률(밭별), Spearman ρ | **ρ ≥ 0.6, p < 0.05** |
| 등급 예측력 | 검사 등급 "높음"인 밭의 착색기 발병률이 "낮음" 밭보다 높은가 | Mann-Whitney p < 0.05 |
| PCR 일치 | 배양 검정 발현 여부 vs PCR 양성 (표본 일부) | 민감도 ≥ 80% |
| 절차 준수 | 농가가 소독·배치를 기준대로 한 비율 (앱 로그 + 방문 확인) | ≥ 90% |

**예측 상관이 핵심이다.** 이게 없으면 나머지가 다 돼도 제품이 아니다.

## Phase 0 — 수동 검정 + 기존 모델 판독 (2주)

**목적:** (1) 배양 검정이 실제로 발현을 만들어내는가, (2) 기존 모델이 챔버 조건의 과실
사진에서 탄저 병반을 잡는가, (3) 2차 부패를 어떻게 처리하는가.

**설계**

- 밭 **2곳 이상** (감염 압력이 다를 법한 곳). 각 24개. 가능하면 1곳은 이미 탄저가
  나온 밭, 1곳은 아직 안 나온 밭 — 감염률 범위를 넓히려는 것.
- [INCUBOX_PROTOCOL](INCUBOX_PROTOCOL.md) 수동 모드 그대로. 격자 종이 4×6.
- 촬영: 매일 1회 이상(가능하면 2회), 고정 거치. 10일.
- 육안 판정: 매일 기록지. 판정자 2명 (본인 + 1명, 가능하면 농기센 담당자).
- 추가 실험(선택): 같은 밭 표본 12개를 **소독 없이** 배양해 소독 효과를 눈으로 확인.
  이 12개는 모델 평가에서 제외.

**분석**

1. `ml/incubation_grid.py`로 칸별 확률 CSV.
2. 기록지를 `label` 열로 병합.
3. `ml/evaluate_incubation.py`: 칸별 정확도·FN·FP·부패 오판·확정 지연. 임계 0.6 기준 +
   ROC로 최적 임계 탐색.
4. 도메인 갭 확인: 정상 과실 칸의 `p_anth` 분포. 중앙값이 0.3 이상이면 갭이 크다 →
   Phase 2에서 파인튜닝 계획.

**통과 기준**

- 칸별 정확도 ≥ 90%, FN ≤ 5% (임계 조정 후).
- 배양 자체: 최소 1곳에서 발현 ≥ 1개 (0이면 검정이 작동했는지 알 수 없음 — 다른 밭 추가).
- 부패 오판율 기록. 30% 이상이면 Phase 2 모델 계획에 `rot` 클래스 추가.

**불통과 시**

- 정확도 < 80%: 도메인 갭. Phase 0 크롭(수백 장)으로 9-class 파인튜닝 후 재평가. 하드웨어는 병행.
- 발현 0: 온도 확인(20℃ 이하였는지), 소독 과다(3분 이상)였는지. 조건 맞춰 재시도.

## Phase 1 — 챔버 1호기 + 펌웨어 (4주)

**목적:** 장치가 7일간 사람 없이 조건을 유지하고 사진을 빠짐없이 보내는가.

**시험**

| # | 시험 | 방법 | 기준 |
|---|------|------|------|
| 1 | 빈 트레이 7일 운전 | 실온 20~25℃ 실내. 60초 로그 | 온도 유지율 ≥ 95%, RH ≥ 98%, 결로 0 |
| 2 | 저온 실내 | 실온 15℃ (겨울 베란다) 3일 | 온도 유지율 ≥ 90% (한계 확인용) |
| 3 | 고온 실내 | 실온 30℃ 1일 | 히터 듀티 0, 경고 `high_temp` 발생 |
| 4 | 네트워크 단절 | Wi-Fi 24시간 차단 → 복구 | 큐 전량 순서대로 수신, 유실 0 |
| 5 | 전원 단절 | RUNNING 중 차단 10분 → 복구 | 상태 복원, 보충 촬영 1회, 히터 재개 |
| 6 | 과열 차단 | 센서 분리 / 히터 위에 센서 | 히터 OFF, `fault_*` 이벤트 |
| 7 | 조명 균일도 | 흰 종이, 5점 측정 | 편차 ≤ 20% |
| 8 | ArUco 검출 | 100회 촬영 | 실패 0 |
| 9 | 과실 7일 운전 | 실제 풋고추 24개 | 결로 0, 사진 판독 가능, 발현 관찰 |

**통과 기준:** 1·4·5·6·8·9 전부 통과. 2·3은 기록.

## Phase 2 — 백엔드·앱 파이프라인 (6주)

**목적:** 촬영이 들어오면 30초 안에 결과가 나오고, 농가가 안내만 보고 검사를 끝내는가.

**시험**

| # | 시험 | 방법 | 기준 |
|---|------|------|------|
| 1 | 단위 | 격자 보정(합성 이미지), 시계열 판정(확률 시퀀스), 평탄·종료, 등급 매핑 | pytest 통과 |
| 2 | 재현 | Phase 0·1 사진을 `/capture`로 재생 | Phase 0 CSV와 칸별 확률 일치 (±0.01) |
| 3 | 지연 | 촬영 수신 → 응답 | ≤ 30초 (CPU) |
| 4 | 멱등 | 같은 (run, seq) 2회 업로드 | 422 + 기존 결과, 칸 중복 없음 |
| 5 | 사용성 | 농가·농기센 3명, 위저드만 보고 검사 시작 → 7일 → 종료 | 3/3 완료, 소독 단계 준수 |
| 6 | 수동 모드 | 4점 지정 UI로 Phase 0 사진 업로드 | 격자 보정 성공 ≥ 95% |
| 7 | 큰글씨 모드 | 125%에서 전 화면 | 잘림·겹침 없음 |

**모델 결정:** Phase 0 결과에 따라 (a) 기존 모델 그대로, (b) 챔버 크롭 파인튜닝,
(c) 챔버 전용 2~3 class. 이 Phase 안에서 결정하고 적용.

## Phase 3 — 현장 검증 (한 시즌)

**목적:** 착색 전 잠복감염률이 착색기 실제 피해를 예측하는가. 그리고 등급 경계가 맞는가.

**협력:** 시군 농업기술센터 1곳 이상. 장치 2~3대를 센터에 두고 대행 검정.

**설계**

- **밭 15곳 이상** (ρ = 0.6을 α 0.05, 검정력 0.8로 잡으려면 n ≈ 19. 15면 ρ ≥ 0.65 필요.
  가능하면 20).
- 밭마다 **착과 후 2주, 4주** 2회 검사 (2회 평균이 단일보다 안정).
- 착색기: 밭마다 **무작위 100과 이상**을 주 1회 3주 관찰, 탄저 병반 과실 비율 = 실제 발병률.
  관찰자는 검사 결과를 모른 채(블라인드).
- 교란 기록: 품종, 살포 이력(약제·날짜), 강우일수, 비가림 여부. 상관 분석에서 살포
  이력을 공변량으로.
- PCR: 검사 표본 중 밭당 6개(발현 3 + 미발현 3)를 보관해 실험실 PCR. 배양 검정의
  민감도·특이도 추정.

**분석**

1. 밭별 (잠복감염률, 실제 발병률) 산점도. Spearman ρ.
2. 등급별 실제 발병률 분포. 경계 0.05·0.20이 실제 피해를 가르는지 — 안 가르면 경계 이동.
3. 살포 이력 보정 후 부분상관.
4. PCR 대비 민감도.

**통과 기준:** ρ ≥ 0.6, p < 0.05. 등급 "높음" 밭의 발병률 중앙값 > "낮음" 밭 (p < 0.05).

**불통과 시:** 상관이 0.3~0.6이면 정성 지표(잠복 있음/없음)로 축소하고 등급 2단계로.
0.3 미만이면 배양 검정 자체가 현장 예측에 부적합 — 제품 중단 판단.
